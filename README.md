# Akan Name Generator

The Akan Name Generator is a simple web or CLI tool that generates a Ghanaian Akan name based on the user's date of birth and gender. In Akan culture, children are named after the day of the week they are born. This tool helps users discover their traditional Akan name quickly and accurately.

## 🌍 About Akan Names

In the Akan culture of Ghana, the day on which a child is born determines their "day name." Each day has a male and female version of the name.

| Day       | Male Name | Female Name |
|-----------|-----------|-------------|
| Sunday    | Kwasi     | Akosua      |
| Monday    | Kwadwo    | Adwoa       |
| Tuesday   | Kwabena   | Abena       |
| Wednesday | Kwaku     | Akua        |
| Thursday  | Yaw       | Yaa         |
| Friday    | Kofi      | Afua        |
| Saturday  | Kwame     | Ama         |

## 🚀 Features

- Input a date of birth and gender
- Calculates day of the week
- Returns the corresponding Akan name
- Easy-to-use interface (CLI/Web)
- Lightweight and fast
